# Watermelon

This example problem is adapted from Codeforces 4A, but the input and output format follow the Hacker Cup convention.

You are given `T` test cases. For each test case, you are given one integer `w`, the weight of a watermelon.

Determine whether it is possible to split the watermelon into two parts such that:

- both parts have positive integer weight
- both parts have even weight

For each test case, print `Case #x: YES` if the split is possible. Otherwise print `Case #x: NO`.

## Input Format

- The first line contains one integer `T`.
- Each of the next `T` lines contains one integer `w`.

## Output Format

- Print exactly one line per test case.
- The line for case `i` must be `Case #i: YES` or `Case #i: NO`.

## Constraints

- `1 <= T`
- `1 <= w <= 100`
